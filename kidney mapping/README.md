# Kidney Mapping Reproducibility

This directory reproduces the **Xenium-to-Visium HD mapping** and downstream analyses for the **chronic kidney disease (CKD)** dataset presented in **Figure 6**.

The workflow performs:

- Spatial alignment of single-cell **Xenium** data with **Visium HD** data using **SpaOT/FPGW**
- Comparison with the **moscot** baseline
- Evaluation of mapping quality at both tissue and glomerulus levels
- Visualization of transport plans on H&E images
- Expression imputation from Visium HD to Xenium
- Downstream cell-cell communication analysis using **COMMOT**

---

## Required Input Data

The scripts expect the following preprocessed datasets and associated histology images:

| File | Description |
|------|-------------|
| `outs_04/segmented_outputs/seg.h5ad` | Visium HD dataset |
| `outs_04/spatial/tissue_hires_image.png` | Visium HD H&E image |
| `Xenium_adata/IU04.h5ad` | Xenium dataset |
| `Xenium_adata/IU04_with_cell_type.h5ad` | Xenium dataset with cell-type annotations transferred from scRNA-seq |
| `Xenium/HE_images/0015383__IU04.TIF` | Xenium H&E image |

> **Note:** The original dataset is currently unavailable for public download.

## Scripts

| Script | Description |
|---------|-------------|
| `fig6b_run_xen_hd_spaOT.py` | Computes SpaOT/FPGW transport plans between Visium HD and Xenium for each spatial region. |
| `fig6b_run_xen_hd_moscot.py` | Runs the **moscot** baseline on the same mapping task for comparison. |
| `fig6a_align_with_plan.py` | Applies the transport plan for barycentric projection and visualizes slice alignment. |
| `fig6cd_Assessment_hull_cellconflict.py` | Evaluates mapping quality using compactness and conflict metrics, including hull ratio and cell conflict. |
| `fig6e_plot_plan_with_hne.py` | Overlays selected transport correspondences on H&E images for qualitative assessment. |
| `fig6f_Assessment_glom_accuracy.py` | Computes glomerulus-level mapping accuracy metrics. |
| `fig6g_plot_plan_in_glom_with_hne.py` | Visualizes transport correspondences within selected glomeruli. |
| `fig6h_run_xen_hd_glom.py` | Computes per-glomerulus SpaOT/FPGW transport plans for downstream analyses. |
| `fig6h_imputed_commot.py` | Imputes Visium HD expression onto Xenium cells and performs COMMOT ligand-receptor and pathway communication analysis. |
| `fig6h_imputed_commot_ct.py` | Visualizes COMMOT communication results with cell-type annotations. |

## Recommended Execution Order

Run the scripts from the repository root in the following order:

```bash
python "reproducibility/kidney mapping/fig6b_run_xen_hd_spaOT.py"
python "reproducibility/kidney mapping/fig6b_run_xen_hd_moscot.py"
python "reproducibility/kidney mapping/fig6a_align_with_plan.py"
python "reproducibility/kidney mapping/fig6cd_Assessment_hull_cellconflict.py"
python "reproducibility/kidney mapping/fig6f_Assessment_glom_accuracy.py"
```

## Main Outputs

The workflow generates the following outputs:

- **Transport plans**
  - Region-level SpaOT/FPGW transport plans
  - Glomerulus-level SpaOT/FPGW transport plans
  - moscot baseline transport plans
- **Mapping evaluation**
  - Hull ratio metrics
  - Cell conflict metrics
  - Glomerulus-level accuracy results
- **Visualization**
  - H&E overlay figures illustrating transport correspondences
  - Tissue and glomerulus alignment visualizations
- **Downstream analysis**
  - Imputed Xenium expression profiles
  - COMMOT ligand-receptor communication results
  - Pathway-level cell-cell communication visualizations

---

## Notes

- Several visualization scripts contain manually tuned coordinate offsets for the **IU04** tissue image to improve alignment between spatial coordinates and H&E images.
- If different image exports or resolutions are used, verify the coordinate alignment before interpreting the overlay figures.
- The scripts contain several hard-coded input/output paths. It is recommended to run the workflow from the **repository root** or update the paths accordingly.
- Downstream analyses reuse transport plans generated by earlier scripts, so the recommended execution order should be followed.
